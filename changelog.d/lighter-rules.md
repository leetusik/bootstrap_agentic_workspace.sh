# Lighter rules: the agent's own browser, playwright-cli

- **The agent's browser is `playwright-cli`, driven from the shell.** Every real-browser check (verification, the review's walkthrough, design fidelity, a PR body's screenshots) runs on `@playwright/cli` 0.1.25: headless, on a throwaway profile, never the operator's. The agent installs it (`npm install -g @playwright/cli@0.1.25`, then `playwright-cli install-browser chrome-for-testing` when no browser is found), starts, restarts (`kill-all`) and closes it itself; the shipped settings allow `Bash(playwright-cli:*)`, `Bash(npm install -g @playwright/cli:*)` and `Bash(npm i -g @playwright/cli:*)`, so no prompt stops it. A saved sign-in is a `state-save` file the operator makes once, named in `## Operator Runtime`'s new `Saved sign-in:` line; only a credential, a sign-in or a paid account stops a run. The dedicated Chrome profile, its recorded id, the select-first step and the "third halt" are retired, and `slice-executor` no longer carries the Claude in Chrome tools: Claude in Chrome is used only when you ask an agent to use your own browser. The procedure lives in `design-cowork`'s `reference/build.md`.
- **Migration notes.** Run `npm install -g @playwright/cli@0.1.25` once per machine (the `update-workspace` skill now does it). In your operations doc's `## Operator Runtime`, retire the `Agent's Chrome deviceId:` line, set `Browser instrument for the agent:` to playwright-cli and add `Saved sign-in:` (the seed's shape in `installer/payloads/doc_bodies/operations.md`), with `doc-new-version`. Claude in Chrome (the extension, `/chrome`, the agent profile) is no longer needed for agents.
