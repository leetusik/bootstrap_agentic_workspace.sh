2. `CHANGELOG.md`: insert a `## v35 — 2026-08-29` section **above** `## v34`, in the file's established voice (a bold **Why this release** lead bullet, then what changed, then a **Migration notes** line). Substance, all of it already true in the tree:

Prompt caching was examined and left unchanged: Claude Code already caches the prefix automatically; a 1-hour subagent TTL is a net loss on the write/read arithmetic. Size is the lever.
   - **`phase.md` is now bounded state, edited under `PHASE_MD_BUDGET` (200 lines / 16 KB):** seeded from `works/templates/phase.md` (embedded fallback) with `## Objective`, an engine-generated `## Slices` table between `<!-- slices:begin -->` / `<!-- slices:end -->` (regenerated by `rebuild`, so by `next` / `new-slice` / `finish-slice`; markers must be alone on their line; no markers = no-op; change-only write; `phase.md` is not a generated file), `## Decisions` (replace, never stack), `## Doc impact` and `## Operator Questions` (append-only), `## Notes for later slices` (tagged, consumed), `## Now` (rewritten, last). `## Context` / `## Findings & Notes` / `## Constraints` / `## Open Questions` left the seed.

   - **Migration notes:** existing `phase.md` files are preserved untouched by `--update` (no markers → the engine never writes them); a phase in flight keeps its old shape until archived, or can be migrated by hand by adding the marker pair and the new sections — the budget warning skips `done` phases, so pre-v35 notebooks never nag. `finish-slice` without `--outcome` still works (warning only). `CLAUDE.md` grew ~1 KB; slimming it is deferred job D8.
   Keep it proportionate to the v34 entry — dense, not longer.
