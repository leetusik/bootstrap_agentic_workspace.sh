## Deviations and judgment calls

None from `plan.md`'s scope. Two calls made inside it:

1. **Smoke asserts were added, not replaced.** The plan anticipated that an existing assert might pin wording this slice supersedes; none did. Rather than leave the new protocol unpinned, the invariants above were added *inside Test 0's existing python block*, which keeps the count at the plan's 137 baseline (a new `ok`/`bad` line would have changed it) and matches the file's convention of pinning only safety-critical rules.
2. **The per-slice re-read of `works/state.json` was dropped alongside `works/backlog.md`** in `do-whole-phase`. The plan named only the backlog; both are printed by `next`, `intent.md` part 4 puts `works/state.json` + `next` at *session start*, and leaving one of the pair in place would have contradicted the reason given for dropping the other. Named explicitly in the skill so it is a stated rule, not an omission.

Also worth flagging for the review, and recorded as a `## Decisions` line: the executor prompt grew **18442 → 21651 bytes** (+3.2 KB per dispatch). That is the price of carrying the notebook protocol into every dispatch, and it is bought back many times over by the reads it removes (the 330 KB doc set and the 54 KB `docs/index.json` no longer read up front, plus a notebook capped at 16 KB).
