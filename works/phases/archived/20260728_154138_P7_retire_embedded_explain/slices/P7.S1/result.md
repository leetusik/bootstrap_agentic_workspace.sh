# Result — P7.S1: Remove explain from the distribution

Retired the embedded explain feature from the bootstrap distribution in one coherent change and
rebuilt the single-file installer. All validation green.

## What changed

**Deleted (whole dirs):**
- `.claude/skills/explain/` (SKILL.md)
- `.agents/skills/explain/` (SKILL.md + agents/openai.yaml)

`build.py` discovers skills from disk (`glob("*/SKILL.md")`), so deleting the dirs drops them from
the embedded `PAYLOADS` on rebuild — no build-code change needed.

**`installer/wrapper.sh`** — removed all four explain bits: the `--with-explain` usage line, the
`with_explain=0` init, the `--with-explain) with_explain=1; shift ;;` case arm, and
`export WITH_EXPLAIN="$with_explain"`. The generic `-*) die "unknown option $1"` arm now rejects the
flag.

**`installer/main.py`** — bumped `WORKSPACE_VERSION` 14 → 15; removed the entire optional-skill block
(the `WITH_EXPLAIN` env read, the `--update` keep-refresh special case, `OPTIONAL_SKILLS`, and the
`_excluded` filtering of `CLAUDE_SKILLS`/`CODEX_SKILLS`). Those two skill lists now flow unfiltered
from the sorted `PAYLOADS`-derived sets (lines 57–58) into `MANAGED_DIRS`/`MANAGED_FILES`. Left
`flag_stale_skills` and `OBSOLETE_MACHINERY` untouched (per phase.md: `flag_stale_skills` is generic
and already produces the intended `--update` behavior; `OBSOLETE_MACHINERY` is for retired *files*,
not skill dirs).

**`tests/retrofit_smoke.sh`** — kept the Test-5 regressions (lines 173–174: "default install omits
explain") as permanent invariants. Replaced the whole Test 8 block (the old `--with-explain`
install + dual-apply diff loop) with a compact assertion that `--with-explain` is now an unknown
option: the built installer is run with `--with-explain`, and the test asserts non-zero exit, the
`unknown option --with-explain` error message, and that no explain skill dir was created.

**`README.en.md`** — removed the `--with-explain` flag-table row, the optional-explain clause in the
"what gets created" prose, the `explain` skills-table row, and the "`explain` is the one exception"
parenthetical. Added a short blockquote pointer in the skills section: the explainer now ships as a
standalone Claude Code plugin in the knowledge repo, with the `/plugin` install commands and
`/knowledge:explain` usage. Skill counts were re-derived from the repo after deletion, not blindly
decremented: `.claude/skills/*/` = 15 dirs (14 mirrored for both tools + `do-whole-phase` Claude-only)
and `.agents/skills/*/` = 14 dirs. So "14 core Agent Skills, mirrored for both tools" (line ~171),
"15 Agent Skills" (line ~253), and "15 Agent Skills (Claude Code)" (project-structure comment, ~323)
are all correct as-is post-deletion — explain had been counted as the separate "optional" extra, so
removing it left those numbers unchanged.

**`CHANGELOG.md`** — added a new top `## v15 — 2026-07-21` entry (house style: bold-lead bullets)
covering the retirement, the verified `/plugin` install pointer (`/plugin marketplace add
leetusik/knowledge` → `/plugin install knowledge@knowledge`, then `/knowledge:setup` once and
`/knowledge:explain <topic>`, noting the `/explain` → `/knowledge:explain` namespace change), and a
**Migration notes** bullet: existing installs are never auto-deleted; on `--update` the Codex copy

**`bootstrap_agentic_workspace.sh`** — regenerated by `python3 installer/build.py` (278372 bytes);
