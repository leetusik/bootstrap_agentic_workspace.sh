# Phase P20: make the Aside prescription true: the repl surface over Bash, on a dedicated profile

_Intent: see [intent.md](intent.md)._

## Objective

Replace v36's three-surface taxonomy with the two that exist -- 'aside repl' (the Playwright-like surface, driven by the executor itself) and 'aside exec' (Aside's own model driving) -- and prescribe 'aside repl' over Bash as the default, explicitly NOT the MCP transport, recording the measured ~1,344-token-per-session cost as the reason and the listBrowserTabs()/attachBrowserTab() re-attach idiom as the canonical preamble. Name 'claude mcp add -s local aside -- aside mcp' as an optional per-operator escape hatch the workspace neither ships nor prescribes. Require agent Aside runs on a dedicated profile via 'aside --account <id>', never the operator's signed-in one, returning needs_operator when only the personal profile exists. Keep the Linux/CI fallback as written. Rewrite the 'not Playwright' argument as 'not a pre-written assertion suite'. Closes D9, D10, D11. Ships as workspace v37.
