# Plan — P34.S1 (Engine: `compact-gate` and `compact-resume`)

## Context

P34 makes context compaction land only at slice boundaries. This slice builds the two engine subcommands the shipped hooks call: `compact-gate` (the `PreCompact` command, matcher `auto`) decides block/allow from state the engine already keeps, with two fail-safes and a fail-open rule; `compact-resume` (the `SessionStart` command, matcher `compact`) re-injects the pointer and a resume line. The design is pinned in `works/phases/active/P34/phase.md` `## Decisions` (read them all first; the DECOMP's reasoning is in `slices/P34.DECOMP/result.md` and the operator's intent and research notes in `intent.md`). S2 ships the hooks in `.claude/settings.json` and the installer; S3 writes the texts and the `## Doc impact` lines; S4 releases v55. This slice touches `scripts/workflow.py`, `tests/retrofit_smoke.sh` and the rebuilt installer artifact only.

Risk `high` by the DECOMP's named trigger (core invariant): the veto must never fail closed and never make a request fail. Every path through `compact-gate` ends in exit 0; a block is only ever an explicit stdout `{"decision":"block","reason":"…"}`.

## Do

1. **`compact-gate`** (`cmd_compact_gate`), stdin = the hook's JSON. Decision order exactly as `## Decisions`:
   - parse stdin (`json.loads(sys.stdin.read())`; anything unparsable → allow);
   - (a) `trigger != "auto"` → allow;
   - (b) fill ceiling: last line of `transcript_path` whose `type == "assistant"` and has `message.usage` (read the file once, iterate, keep the last; tolerate bad lines) — fill = `input_tokens + cache_read_input_tokens + cache_creation_input_tokens` (missing keys = 0); ceiling = `AGENTIC_COMPACT_CEILING` if set and an int, else 850,000 when `message.model` matches the 1M family (pin the test — e.g. `re.match(r"^claude-[a-z]+-5(?:-|$)", model)` — and name it in the Decision), else 170,000; fill ≥ ceiling → allow (reset the counter). Unreadable/absent transcript or usage → skip (b);
   - (c) cap: counter file `<scratchpad_dir or tempfile.gettempdir()>/agentic-compact-gate-<session_id>.json` (session_id missing → `nosession`); `blocks >= cap` (cap = `AGENTIC_COMPACT_BLOCK_CAP` or 8) → allow and reset;
   - (d) boundary: current slice `in_progress` / `in_review` → block; dirty tree → block; else allow and reset. Dirty = `git status --porcelain --untracked-files=all -- . ':!works/state.json' ':!works/index.json' ':!works/backlog.md' ':!works/deferred.md'` from the workspace's repo (prefix the exclusions correctly in the nested layout: `workflow/works/…` from the host — reuse `_repo_prefix()` / `_status_product_files`'s approach), non-empty → block, with the count in the reason (`dirty: 3 files`). **Verify the exclusion list in a `cp -R` copy**: after a commit there, run `next`, `validate` and `rebuild` and check what they dirty (`docs/index.json` showed up as modified after the DECOMP run — if `validate`/`rebuild` regenerates it, add it to the exclusions and amend the Decision; if only a deliberate command does, leave it). No git / not a repo → skip the rule.
   - A block prints `{"decision": "block", "reason": "<rule>: …"}` to stdout and increments the counter; an allow prints **nothing** to stdout (check the binary for whether an explicit `{"decision":"allow"}` is parsed for PreCompact; if it is not clearly accepted, stay silent) and resets the counter. In **both** cases print one `key=value` trace line to **stderr** — `compact-gate: decision=<allow|block> rule=<manual|ceiling|cap|slice_in_progress|dirty|boundary|error> slice=<id or -> status=<…> fill=<n or -> ceiling=<n> blocks=<n>/<cap>` — so the smoke test and the walkthrough can read why without parsing JSON (stderr on exit 0 goes only to the debug log). Wrap the whole body in `try/except Exception` → allow with `rule=error` and the exception text in the trace. Exit 0 always; never `raise SystemExit` out of it (the `_git` helper raises — use `check=False`).
