# Phase P34: Boundary-gated compaction: veto mid-process, resume at the slice boundary

_Intent: see [intent.md](intent.md)._

## Objective

Make context compaction land only at slice boundaries and recover cleanly when it does. A PreCompact hook on auto-compaction calls an engine command that blocks while the current slice is in progress or the tree is dirty, and allows at a clean boundary (slice done, pending or review done, with a clean tree), with two fail-safes: allow above a hard fill ceiling read from the transcript's usage, and after a cap of consecutive blocks; manual /compact is never blocked. A SessionStart hook on the compact source re-injects the workflow pointer and a resume line (re-read the running skill from disk, the active slice folder and the notebook's ## Now). CLAUDE.md gains a short compact-instructions section naming what the summary keeps and drops. The two execution skills are reordered so the loop invariants and the resume line sit within the first 5,000 tokens. Both hooks ship on for everyone through the installer's settings merge. The auto-compact window stays the operator's personal setting, with the recommended value of about 300k recorded in the operations doc. Runs after P32, which rewrites the same skills. Ships as workspace v54.

- **Two engine subcommands, no hook script:** `compact-gate` (PreCompact) and `compact-resume` (SessionStart) live in `scripts/workflow.py`, which the installer already embeds and nested-rewrites; a file under `.claude/hooks/` would need a `FIXED_LIVE_FILES` entry and its own rewrite. Both read the hook JSON from stdin, need only python3 + git, and **fail open**. (P34.DECOMP)
- **Hook command form (supersedes the plan's `"$CLAUDE_PROJECT_DIR/scripts/workflow.py"` form):** `cd "$CLAUDE_PROJECT_DIR" && python3 scripts/workflow.py compact-gate || true` (and `… compact-resume || true`), `timeout` 15. Why: `NESTED_ENGINE_RE` (`installer/main.py:504`) has a `(?<![\w./-])` lookbehind, so a path glued to `$CLAUDE_PROJECT_DIR/` would **not** be nested-rewritten; after a space it is (→ `workflow/scripts/workflow.py`). The trailing `|| true` makes any engine-level exit (argparse error from a stale engine is exit 2 = a block in Claude Code) a non-blocking 0. (P34.DECOMP)
- **Block mechanism:** `compact-gate` blocks **only** by printing `{"decision": "block", "reason": "…"}` on stdout with exit 0; it never exits 2. **Allow = no stdout at all**, exit 0 — the hooks reference: "The only value for `decision` is `"block"`. To allow the action to proceed, omit `decision` from your JSON, or exit 0 without any JSON at all." Every internal exception → allow (`rule=error`). (P34.DECOMP, allow form pinned by P34.S1)
- **A blocked auto-compaction is re-asked, not abandoned (confirmed, P34.S1):** Claude Code 2.1.296 binary, auto-compact function (offset ≈197831803): `catch(Rt){if(l(Rt).startsWith(M7)){…return{kind:"hook_blocked",routedThroughReactive:!1}}` — the PreCompact-block branch returns **before** `Pon(…)`, the failure-tracking return every other failure branch takes, and sets no sticky flag; the reactive route likewise returns `{kind:"hook_blocked",…}` before `Pon`; `autoCompactThreshold:E5(r,V)` is computed per call. The in-process runner logs `compaction blocked by PreCompact hook; continuing uncompacted` (≈75300213), and the UI shows `Compaction blocked by PreCompact hook: ` + the reason (≈78289748), so the `reason` reaches the operator. Further binary reads were refused by the auto-mode classifier; no live probe was run (the reading was unambiguous for the branch that matters).
- **`compact-gate` decision order:** (a) `trigger != "auto"` → allow (manual `/compact` never blocked; the `auto` matcher is the first guard); (a′) **the hook fired inside a subagent** (`agent_id` non-empty — a common hook input field for subagents and in-process teammates) → allow without touching the count (P34.S1: an executor's slice is `in_progress` for its whole life, so the veto would only defer its compaction to the cap; the boundary is the main thread's); (b) **fill ceiling**: fill = `input_tokens + cache_read_input_tokens + cache_creation_input_tokens` of the latest assistant `message.usage` in `transcript_path`; fill ≥ ceiling → allow; unreadable transcript/usage → skip (b), the cap still bounds it (S1 confirms or replaces with a reason); (c) **consecutive-block cap**: per-`session_id` counter ≥ cap → allow and reset; (d) **boundary**: block iff this checkout's current slice (the same stream-scoped `resolve_current` path `next` uses) is `in_progress` or `in_review`, **or** the tree is dirty; otherwise allow and reset the counter. Every block increments the counter, and **a block the counter cannot record allows instead** (`rule=error`, `block counter unwritable`) — an uncountable block could repeat forever. The `reason` names the rule and the release: `slice P34.S1 in_progress -- compaction waits for the slice boundary (block 1/8; compaction is allowed at a clean slice boundary, above 850000 tokens, or after 8 blocks in a row)` / `dirty: 3 files uncommitted (your own uncommitted work counts too) -- compaction waits for a committed boundary (…)`. (P34.DECOMP, a′ and the uncountable block by P34.S1)
- **Statuses:** `in_progress` and `in_review` block (the engine never sets a slice `in_review` itself, only `set-slice-status` does, and it marks unfinished work; the cap bounds it); `todo`, `ready`, `pending`, `done`, `blocked`, `changes_requested` allow; a `pending`/`blocked` phase yields no current slice (`resolve_current`), so the acceptance gate allows. (P34.DECOMP)
- **Dirty tree** = `git status --porcelain --untracked-files=all -- . ':(exclude)works/state.json' ':(exclude)works/index.json' ':(exclude)works/backlog.md' ':(exclude)works/deferred.md' ':(exclude)docs/index.json'` run from the workspace root (`COMPACT_DIRTY_EXCLUDE`). `docs/index.json` added by P34.S1: verified in a `cp -R` copy, `next` rewrites `works/state.json`/`index.json` (first run only), `validate` nothing, and **`rebuild` restamps `docs/index.json`'s `last_rebuilt_at` on every run**; a real doc change also writes `docs/versions/`/`docs/current/`, so nothing is lost. **Nested layout = two repos** (the workspace repo `workflow/` and the host): the workspace repo with the same exclusions, **plus** the host's product (`_host_pathspec()`: everything but the nested folder); paths deduplicated by absolute path. A repo without git → skipped (fail open). (P34.DECOMP, amended by P34.S1)
- **Fill ceiling:** fill = `input_tokens + cache_read_input_tokens + cache_creation_input_tokens` of the last main-thread (`isSidechain` not true) assistant line in `transcript_path` with a non-zero sum (read from the file's last 4 MB, the whole file only when the tail has none). 850,000 when its `message.model` matches **`^claude-[a-z]+-5(?:[-\[]|$)`** (`COMPACT_1M_MODEL_RE`: every Claude 5 id the operator's transcripts carry — `claude-opus-5-5`, `claude-opus-5`, `claude-fable-5-1`, `claude-sonnet-5-5`, `claude-sonnet-5`, `claude-haiku-5-5`, `claude-opus-5-5[1m]`), else 170,000 (85% of 200k; e.g. `claude-haiku-4-5-20251001`); override `AGENTIC_COMPACT_CEILING` (positive int). No readable usage → rule (b) skipped, the cap bounds it. **Cap:** 8 consecutive blocks, override `AGENTIC_COMPACT_BLOCK_CAP` (positive int). When in doubt, allow. (P34.DECOMP, regex pinned by P34.S1)
- **Counter location:** untracked only — `<scratchpad_dir or tempfile.gettempdir()>/agentic-compact-gate-<session_id>.json` (`scratchpad_dir` is a documented common hook input field since 2.1.257; a missing `session_id` → `nosession`; unsafe characters → `_`), content `{"blocks": n, "updated_at": …}`; an allow deletes it. Never a path in the tree (a file there would itself make the tree dirty). (P34.DECOMP, file name pinned by P34.S1)
- **Trace line (P34.S1):** every `compact-gate` run prints exactly one line to **stderr** (stdout carries only a block's JSON): `compact-gate: decision=<allow|block> rule=<manual|subagent|ceiling|cap|slice_in_progress|dirty|boundary|error> slice=<id|-> status=<status|-> dirty=<n|-> fill=<n|-> ceiling=<n|-> blocks=<n>/<cap>` plus ` error=<text>` on `rule=error`; `blocks` is the count after the decision. On exit 0 Claude Code sends hook stderr only to the debug log.
- **Malformed nested marker (P34.S1):** `main()`'s refusal on a malformed `.agentic-nested.json` exempts `compact-gate` and `compact-resume` (with `validate`), so the hooks still run and fail open.
- **`compact-resume`:** prints, as facts, the `next` output (pointer, `WAITING ON OPERATOR` if any) and one resume line — re-read the running skill's `SKILL.md` from disk (only its first 5,000 tokens were re-injected), the active slice folder (`plan.md`, `result.md`) and `phase.md`'s `## Now`; running executors are listed by the harness. Always under 10,000 characters; `next`'s rebuild side effect is acceptable. (P34.DECOMP)
- **Hooks merge (installer):** additive by `command` — for each event and matcher group in the payload, append our handler unless a handler with the same `command` already exists anywhere under that event; never remove or reorder an adopter's hooks; idempotent. Applied on `--update`, retrofit and the nested `settings.local.json` present-file path (absent-file paths already write the whole payload). (P34.DECOMP)
- **Merge helper (P34.S2):** `_merge_settings_dict(theirs, ours) -> dict` in `installer/main.py` is the one pure merge (permissions union + hooks, per the rule above) used by `_merge_settings_json` (root: a non-object file, an unparseable file or **any malformed shape** -> the `.claude/settings.workspace.json` sidecar, the target byte-identical) and by the nested `settings.local.json` present-file path (malformed -> `_nested_refuse`, nothing written). Malformed = `permissions` not an object, `allow`/`deny` not a list, `hooks` not an object, an event not a list of objects, a group's `hooks` not a list of objects (a ValueError). Groups match on `matcher` equality (absent = absent). Dedup is by `command` anywhere under the event; a handler the adopter removed is re-added on the next merge. Both hooks ship in `.claude/settings.json` (`hooks` after `permissions`); nested installs get them through the rewrite (`python3 workflow/scripts/workflow.py ...`). Smoke: 289 PASS (+9). (P34.S2)
